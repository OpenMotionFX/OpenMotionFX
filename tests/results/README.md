# Test results

Raw data from hardware tests, stored exactly as the owner reported it.

- One folder per test: `tests/results/T-NNN/`, with a `README.md` giving the date, who ran it and the device builds.
- Raw files are not edited. Analysis goes in a separate file next to them.
- Large media is not committed: store a checksum and a small extract.
- A claim in [docs/ai/CLAIMS.md](../../docs/ai/CLAIMS.md) becomes VERIFIED only by pointing at a file here (`verify-claim` skill).
