# Hardware test cards

Step-by-step tests the owner runs on real hardware or the phone (level L4 in [docs/ai/TESTING.md](../../docs/ai/TESTING.md)).

- One file per test, named `T-NNN-short-name.md`.
- Written with the `hardware-test-card` skill: purpose, equipment, numbered steps with one action each, what to record, pass numbers.
- Results go to `tests/results/T-NNN/`.

No cards exist yet. The first ones belong to Phase 0: the pulse offset between the two boards, and the sync LED.
